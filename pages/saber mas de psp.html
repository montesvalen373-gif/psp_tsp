¿Que es el PSP?

El PSP (Personal Software Process o Proceso Software Personal) es un marco estructurado de prácticas disciplinadas diseñado para que los desarrolladores de software puedan planificar, medir y gestionar su propio trabajo a nivel individual.


Objetivo del PSP

dotar a los ingenieros y desarrolladores de software de un marco disciplinado de autocontrol para mejorar sus hábitos de trabajo individuales. Busca que cada programador pueda planificar sus proyectos de manera precisa, medir y controlar la calidad de su código, y reducir drásticamente los defectos desde las primeras etapas de desarrollo, optimizando así su productividad y eficiencia personal.


Niveles del PSP

Son como las etapas que vas superando en un videojuego para volverte un pro programando, midiendo tus tiempos y evitando complicaciones o retrasos.

Nivel 0 / 0.1

Línea Base del PSP: Se enfoca en registrar el proceso actual, el tiempo dedicado, los defectos encontrados, los estándares de código y la medición inicial del tamaño del software.

Nivel 1 / 1.1

Proceso Personal de Planeación: Introduce la estimación formal de tamaño, el reporte de pruebas y un calendario para la planeación de tareas.

Nivel 2 / 2.1

Manejo Personal de Calidad: Añade la revisión rigurosa de diseño y código, así como el uso de plantillas de diseño específicas.

Nivel 3

Proceso Personal Cíclico: Permite el desarrollo de proyectos de mayor escala mediante la aplicación de ciclos interactivos personales.


Ventajas y Desventajas

Ventajas

  • Mejora la productividad de las personas involucradas.
  • Reduce los errores de codificación.
  • Mejora el control del trabajo individual.
  • Facilita identificar fortalezas y debilidades para mejorar.
  • Mejora la calidad del producto.

Desventajas

  • Tensión emocional por sentirse controlado.
  • Tiempo que implica llevar el registro de los tiempos.

Certificación PSP

Alineada con modelos como CMMI, ISO o similares. Ayuda a mejorar la estimación y planeación, asumir compromisos que se pueden cumplir, administrar y reducir defectos.
